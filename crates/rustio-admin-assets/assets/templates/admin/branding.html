Bake it — build-time

1 — generate a tokens.css from your brand colour:

rustio-admin theme generate --brand '{{ current_accent }}' --out generated/tokens.css

…or interactively: rustio-admin theme wizard

2 — serve it (the running admin appends it after the baked CSS — restart to apply):

RUSTIO_TOKENS_CSS=generated/tokens.css cargo run

Quick code-level accent, no tokens.css:

Admin::new().accent_color("{{ current_accent }}")

rio-theme computes contrast-safe shades at build time; the runtime never links it.
