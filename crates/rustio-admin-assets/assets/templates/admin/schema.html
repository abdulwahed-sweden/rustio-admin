Change the schema

Build-time, network-free, atomic. Add a model and a field, preview, commit:

rustio-admin add model Invoice
rustio-admin add field Invoice amount decimal
rustio-admin plan
rustio-admin commit

Or import a whole schema at once — the JSON may be authored by a human or an external assistant; RustIO runs no AI:

rustio-admin import schema.json
rustio-admin plan
rustio-admin commit
