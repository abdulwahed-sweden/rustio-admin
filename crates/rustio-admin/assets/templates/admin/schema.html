Edit the schema — build-time

network-free, atomic; the runtime never generates code

Add a model and a field, preview, then commit:

rustio-admin add model Invoice
rustio-admin add field Invoice amount decimal
rustio-admin plan      # preview the changes (read-only)
rustio-admin commit    # apply atomically

…or import a whole schema at once (an external AI assistant or a human can author the JSON — RustIO runs no AI):

rustio-admin import schema.json   # records add_model / add_field events
rustio-admin plan
rustio-admin commit

Start a fresh Builder project: rustio-admin builder new my-project · contract: docs/design/DESIGN_BUILDER.md
