E

Primary colour

Keep #1F5797. main's default --blue is #1f5797; rustio-admin's --rio-rust is the same value. main lets a project's rustio.design.json override the primary (and the focus) per project; rustio-admin's equivalent is AdminTheme, which overrides the primary and leaves focus alone. The shared default is what makes the family; per-project overrides are each product's own mechanism.
