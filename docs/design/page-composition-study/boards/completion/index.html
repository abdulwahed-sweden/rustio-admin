D

⌘K and the search page — two jobs

⌘K · jump

Fast navigation and command discovery. A few results, grouped by model, Enter opens the first. It gains a foot that says what Enter does and a way out to the full search.

/admin/search · results

The result-oriented experience: every match with its context, counted per model, scoped, and handed on to each model's own list where filters and sort live.

/admin/<model>?q= · filter

Unchanged. The deep tool: the find row, filters, sort, pagination and bulk actions of one model. The search page links into it; it never replaces it.
